# 2.5 검증 자료

Java 25에서 mvn clean verify로 검사합니다. Paper 26.2 build 135, API 26.2.build.135-stable, 기존 공식 음성 API 2.6.25를 사용합니다.

RuntimeProbe.java는 loopback 격리 서버 전용입니다. 운영 plugins에 넣지 마세요. 2.4 서버의 네 테스트 계정과 실제 플레이어/월드 저장 자료를 복사하고 2.5 JAR만 교체했습니다. phase1은 설정 이전과 실제 부분 생성, 종료/재시작 후 phase2는 자동 이어짓기·원래 상자 보존·블록 39,031개 대조·NPC/GUI·봇 설정 오류 처리, 다시 종료/재시작 후 phase3은 재생성 방지·설정/아이템 유지·NPC 중복 방지·백업을 검사합니다.

중단 시점을 확실히 만들기 위해 테스트 설정에서만 최초 자동 생성을 끄고 틱당 100개로 시작했으며, OP 명령으로 실제 생성한 뒤 도중에 정상 종료했습니다. 다음 시작은 별도 명령 없이 기록에서 자동 재개합니다. 배포 기본값은 자동 생성 켜짐·틱당 1,200개입니다. 누락 설정에 자동 생성 기본값이 추가되는 것은 단위 검사에서도 확인합니다.

일부 클릭/명령·피해·권한과 테스트용 물건은 Bukkit API/리플렉션으로 주입합니다. HTTP 봇 인증/전송/제한/오류는 로컬 HttpServer와 모의 응답으로 검사합니다. 실제 사용자의 Discord 토큰이나 운영 채널에 연결하지 않았습니다. 최초 서버 준비 단계의 환경 시간초과는 새 격리 폴더에서 다시 확인했습니다.

spawn-plan.json은 실제 서버에서 블록 대조를 마친 설계 데이터입니다. render_spawn_preview.py는 이 자료로 만든 블록 설계 미리보기이며 게임 클라이언트 스크린샷이 아닙니다. previous-2.4와 previous-2.2는 과거 자료로 이번 검사 수에 합치지 않습니다.
