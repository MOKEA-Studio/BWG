## 발견 후 수정

- 생략된 `clone-remote-port: false`가 이미 false인 경우에도 설정 변경·재시작 필요로 보이던 판정을 수정하고 회귀 검사를 추가했습니다.
- Geyser 플러그인이 로드되었어도 내부 초기화가 실패하면 정상 연동으로 표시하지 않도록 실행 상태·종료 상태·수신 서비스 객체를 함께 확인했습니다.
- OP 상태 GUI는 기존 27칸에서 새 상태 항목 때문에 범위를 넘지 않도록 표시 공간을 확장했습니다.
- 코인 표시가 이동·채광·대기열 알림에 덮이는 경로를 공통 액션바로 합쳤습니다.
- 설치 도우미는 반복 설치 때 불필요한 보관 폴더를 안내하지 않도록 했고, 부모가 파일인 경로 때문에 쓰기가 실패한 경우에도 원본 복원과 결과 안내가 정확하도록 수정했습니다.

## 검사 환경과 범위

검사 환경의 외부 프록시는 HTTPS CONNECT에 공식 Geyser 내부의 고정 5초보다 긴 지연이 있었습니다. 테스트 실행기 안에서만 같은 허용된 외부 프록시로 공개 Microsoft 메타데이터용 터널을 미리 열어 TLS 연결 지연을 줄였습니다. 인증·암호화를 끄거나 키를 바꾸지 않았습니다. 이 코드는 서버 설치 과정에서 사용되지 않습니다.

Paper의 OSHI 정보 조회·외부 인증키/버전 조회 경고는 컨테이너 네트워크·시스템 정보 제한으로 발생했고 기능 검사 결과와 구분했습니다. 실제 휴대폰 Xbox 계정 로그인, 운영 서버의 외부 공유기·DNS·방화벽, 모든 터치 UI 동작과 대규모 동시 접속 부하는 검사하지 않았습니다. 베드락 네트워크 검사는 같은 격리 서버에서 서비스 활성과 TCP 응답까지 확인한 것입니다.

기존 환영 인사는 실제 접속자가 있는 Paper에서 채팅 이벤트를 주입했습니다. 무덤 만료는 서비스의 시각 인수를 이용해 검사했습니다. 이전 버전의 모든 네이티브 시나리오를 재실행했다는 의미는 아닙니다. 이전 검증은 verification/previous-*에 별도로 보관하고 이번 횟수에 합산하지 않습니다.

상세 결과는 verification/server-checks.txt, bedrock-network.txt, installer-checks.txt, unit-tests.txt, runtime-facts.json에 있습니다.
